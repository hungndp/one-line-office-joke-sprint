One office joke, one line: an employee replies all to 4,000 colleagues to say "please stop replying all" — and becomes the reason the button asks "are you sure?". A Python program writes the single line to the make.fun output directory, where the gate checks it is UTF-8 text of 1 to 200 characters.

## Run it

```sh
python3 main.py
```
